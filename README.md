# FODEX STUDIOS // Creative Video Editing & Visual Portfolio

Official portfolio website of **Shaveen Shanidu** (Fodex Studios) — Lead Video Editor, Colorist & Digital Artist.

## 🎬 Features
- **Cinematic & Commercial Showcases**: High-impact video reel players and project breakdowns.
- **Gaming & AMV Edits**: Fast-paced music syncing and kinetic visual effects.
- **Photo Editing & Color Grading**: High-res before/after comparison viewers and commercial photo manipulation.
- **Direct Lead Generation**: Realtime contact form integration powered by Web3Forms & direct WhatsApp chat action.
- **Sleek Dark Mode UI**: Built with dark aesthetic, custom timeline scrubber animations, and smooth Framer Motion transitions.

## 🛠 Tech Stack
- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS + PostCSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Forms / Backend:** Web3Forms API
- **Build Tool:** Vite

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
